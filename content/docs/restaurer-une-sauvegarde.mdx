La restauration remplace les données actuelles de DigiStock par celles d'une sauvegarde. Elle sert après une panne, lors d'un changement d'ordinateur, ou pour revenir en arrière après une erreur importante.

<Callout type="warning" title="Attention">
La restauration remplace les données présentes. Les opérations faites après la date de la sauvegarde seront perdues. Si possible, créez d'abord une sauvegarde de l'état actuel.
</Callout>

## Restaurer sur le même ordinateur

1. Ouvrez les paramètres de sauvegarde de DigiStock.
2. Choisissez la restauration.
3. Sélectionnez le fichier de sauvegarde.
4. Confirmez, puis attendez la fin de l'opération.
5. Vérifiez quelques ventes et produits récents.

## Changer d'ordinateur

1. Sur l'ancien ordinateur, créez une sauvegarde et copiez-la sur une clé USB.
2. Sur le nouvel ordinateur, [installez DigiStock](/docs/installation).
3. Restaurez la sauvegarde depuis la clé USB.
4. Vérifiez vos données avant de reprendre les ventes.
