DigiStock imprime vos tickets de caisse sur l'imprimante installée dans Windows. La plupart des commerces utilisent une imprimante thermique de tickets.

## Installer l'imprimante

1. Installez l'imprimante dans Windows avec le pilote du fabricant.
2. Imprimez une page de test depuis Windows pour vérifier qu'elle fonctionne.
3. Dans DigiStock, choisissez cette imprimante pour les tickets.

## Choisir le format

Les imprimantes de tickets utilisent généralement des rouleaux de **80 mm** ou de **58 mm** de large. Choisissez dans DigiStock le format correspondant à votre rouleau.

## Contenu du ticket

Le ticket reprend vos [informations d'entreprise](/docs/parametres-entreprise), le numéro de vente, la date, les produits, le total en DH et le mode de paiement. Vous pouvez ajouter un message de bas de ticket, par exemple vos horaires ou une formule de remerciement.

<Callout type="tip" title="Ticket test">
Après chaque modification, faites une vente test et imprimez le ticket pour vérifier la mise en page.
</Callout>

## Problèmes fréquents

| Symptôme | Piste |
| --- | --- |
| Rien ne s'imprime | Vérifiez que l'imprimante est sélectionnée et allumée, et qu'une page de test Windows fonctionne. |
| Texte coupé | Le format choisi (80 / 58 mm) ne correspond pas au rouleau. |
| Caractères bizarres | Mettez à jour le pilote de l'imprimante. |
