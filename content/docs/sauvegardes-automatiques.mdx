Vos données sont enregistrées sur votre ordinateur. Une panne de disque, un vol ou un virus peuvent les faire disparaître. Les sauvegardes automatiques réduisent ce risque sans que vous ayez à y penser.

## Activer les sauvegardes automatiques

1. Ouvrez les paramètres de sauvegarde.
2. Activez les sauvegardes automatiques.
3. Choisissez le dossier de destination.
4. Enregistrez.

## Où enregistrer les sauvegardes ?

Une sauvegarde sur le même disque que DigiStock ne protège pas contre une panne de ce disque. Préférez :

- un **disque dur externe** ou une **clé USB** branchés régulièrement ;
- un **dossier synchronisé** avec un service de stockage en ligne de votre choix.

<Callout type="warning" title="Testez la restauration">
Une sauvegarde n'est utile que si elle peut être restaurée. Faites un test de temps en temps. Voir [Restaurer une sauvegarde](/docs/restaurer-une-sauvegarde).
</Callout>
