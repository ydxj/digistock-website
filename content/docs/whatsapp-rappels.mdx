Relancer un client n'est jamais agréable. DigiStock prépare un message clair et poli avec le solde exact, que vous relisez avant de l'envoyer.

## Envoyer un rappel

1. Ouvrez **Crédits clients** et sélectionnez le client.
2. Choisissez l'envoi d'un rappel WhatsApp.
3. Relisez le message : il reprend le nom du client et le montant dû.
4. Adaptez le ton si besoin.
5. Validez l'envoi.

## Exemple de message

> Bonjour M. Benali, nous espérons que vous allez bien. Votre solde chez nous est de 1 280 DH. Vous pouvez passer le régler quand cela vous arrange. Merci pour votre confiance.

## Conseils

- **Restez cordial** : un client bien traité revient payer et acheter.
- **Choisissez le moment** : évitez les relances le vendredi midi ou tard le soir.
- **Espacez les rappels** et préférez un appel pour les montants importants.

<Callout type="info">
DigiStock n'envoie jamais de rappel automatiquement. Chaque envoi est validé par vous.
</Callout>
