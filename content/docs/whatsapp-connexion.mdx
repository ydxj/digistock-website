DigiStock Premium permet d'envoyer des messages WhatsApp à vos clients et fournisseurs depuis l'application. WhatsApp est connecté **localement**, sur l'ordinateur où DigiStock est installé.

## Avant de commencer

- Un compte WhatsApp actif sur votre téléphone (de préférence le numéro de votre commerce).
- Une connexion Internet au moment de l'envoi des messages.
- DigiStock Premium activé. Voir [Activation Premium](/docs/activation-premium).

## Connecter WhatsApp

1. Ouvrez **WhatsApp** dans la section **Premium** du menu.
2. Lancez la connexion.
3. Suivez les instructions affichées à l'écran pour lier votre compte WhatsApp depuis votre téléphone.
4. Vérifiez que l'état de connexion indique que WhatsApp est connecté.

## Ce que DigiStock fait, et ne fait pas

| DigiStock… | |
| --- | --- |
| prépare le message (texte, montant, document) | Oui |
| vous montre le message avant l'envoi | Oui |
| envoie un message sans votre validation | **Non** |
| envoie des messages en masse automatiquement | **Non** |

<Callout type="info" title="Vous gardez le contrôle">
Chaque message est relu et validé par vous. Rien ne part sans votre accord.
</Callout>

## Déconnecter WhatsApp

Vous pouvez déconnecter WhatsApp depuis le même écran, ou depuis les appareils connectés dans l'application WhatsApp de votre téléphone.
