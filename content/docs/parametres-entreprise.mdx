Les paramètres entreprise regroupent les informations qui identifient votre commerce sur vos documents.

## Informations disponibles

| Information | Où elle apparaît |
| --- | --- |
| Nom commercial | En-tête des tickets, factures et reçus |
| Adresse, ville | Tickets et factures |
| Téléphone, e-mail | Tickets et factures |
| Identifiants légaux (ICE, RC, IF…) | Factures |
| Logo | Factures et, selon le format, tickets |

## Modifier les informations

1. Ouvrez les paramètres de DigiStock.
2. Rendez-vous dans la partie consacrée à l'entreprise.
3. Modifiez les champs nécessaires.
4. Enregistrez, puis imprimez un ticket test pour vérifier le rendu.

Les nouveaux documents utilisent les informations à jour.
