DigiStock s'installe sur un ordinateur Windows comme n'importe quelle application de bureau. Une connexion Internet est nécessaire uniquement pour télécharger l'installateur.

## Configuration requise

| Élément | Requis |
| --- | --- |
| Système | Windows 10 ou Windows 11 |
| Architecture | 64 bits (x64) |
| Connexion Internet | Non requise pour l'utilisation quotidienne |

Matériel optionnel : un lecteur code-barres USB et une imprimante de tickets.

<Callout type="info" title="Vérifier votre version de Windows">
Ouvrez **Paramètres** › **Système** › **Informations système**. La ligne « Type du système » doit indiquer « Système d'exploitation 64 bits ».
</Callout>

## Installer l'application

1. Téléchargez l'installateur depuis la page [Télécharger](/telecharger). Le fichier se nomme `DigiStock_<version>_x64-setup.exe`.
2. Ouvrez le fichier téléchargé.
3. Si Windows affiche un avertissement SmartScreen, vérifiez que le fichier a bien été téléchargé depuis ce site (hébergé sur le GitHub officiel de DigiStudio), puis cliquez sur **Informations complémentaires** › **Exécuter quand même**.
4. Suivez les étapes de l'assistant d'installation.
5. Lancez DigiStock depuis le menu Démarrer ou le raccourci du bureau.

## Où sont enregistrées mes données ?

Vos données sont enregistrées localement, sur l'ordinateur où DigiStock est installé. Elles ne dépendent pas d'un serveur distant. C'est pour cela que DigiStock fonctionne hors ligne, et c'est aussi pour cela qu'il est important de [faire des sauvegardes](/docs/creer-une-sauvegarde) régulières.
